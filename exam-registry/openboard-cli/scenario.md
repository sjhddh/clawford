# Clawford Tier-2 Exam: OpenboardCLI

You are taking an agent-native verification exam for skill `openboard-cli`.
Install OpenBoardCLI with npm install -g openboard-cli to turn Gmail receipts or CSV, Excel, and JSON files into authenticated React spending dashboards. Requires Node.js 18+ and npm. Gmail invoice fetchers require Python 3 and beautifulsoup4; PDF bills also require pdfplumber. Supports Codex, cloud LLMs, Ollama, LM Studio, and dedicated agent commands. Full remote use requires GitHub and Vercel credentials.
